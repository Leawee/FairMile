# FairMile 产品需求文档

给美国自雇和 1099 人士用的 IRS 里程与花费账本。V1 做可编辑行程、按日期套用税率、完整导出，不与全自动追踪巨头硬撞。

**定位一句话：** FairMile 是一本可核对、可导出的 IRS 里程账本：开车时点开始和结束，补上目的地与商务事由，按日期套对标准里程税率，导出可交给会计或用于报销的 PDF 与 CSV。它不是报税软件，也不保证抵扣通过。

## 背景与定位

美国自雇人士、房地产经纪人、顾问、承包商以及部分司机与外卖司机，用自己的车跑业务时，报税或报销需要留下日期、里程、起终点和商务事由。纸笔和表格难以坚持；现有自动追踪 App 年费可达 90 至 140 美元，且自动切段不准时很难改。

2026 年 11 月 9 日，MileIQ 仍是美区 Finance 畅销榜第 1，且 11 月 1 日至 9 日连续 9 天第 1；Everlance 排第 12。这是榜单位次，不是下载量或收入数字。接下来是申报 2026 年税的窗口（约 2027 年 1–4 月）。IRS 今年年中调过标准里程税率：商务里程 1 月 1 日至 6 月 30 日为每英里 72.5 美分，7 月 1 日至 12 月 31 日为 76 美分。按日期算对，是 V1 的明确差异点。

## 目标用户

| 用户 | 场景 | 为什么付费 |
| --- | --- | --- |
| 自雇专业人士（房地产、顾问、承包商） | 驱车见客或跑工地，年底要做 Schedule C | 需要可交给会计的完整记录，而不是又一笔贵的自动追踪 |
| 1099 工作者与部分司机 | 经常跑车，要么报税要么报销 | 希望记得下、改得动、导出清楚 |
| 需要报销里程的职员 | 公司要求提交里程单 | 关心 PDF 格式完整，不一定需要税务功能 |

V1 不把大型车队管理员或企业财务团队当主要客户。也不做给会计师事务所用的多客户后台。

## 目标与非目标

### V1 要达成

1. 用户能在出车时用「使用期间」定位记下可信的路径里程，也能手动补记。
2. 行程可改起终点、可切分和合并，混跑公事与通勤时不必整段重做。
3. 按行程日期套用 2026 年 IRS 两段商务税率，税率表可更新，不写死。
4. 可导出含事由、目的地、税率区间说明的年度 PDF 与 CSV。
5. 本地优先，不强制注册；免费下载加试用，年费定在 39.99 美元。
6. 仅在美区（及其他后续主动打开的非中国大陆商店）分发，V1 不上中国大陆 App Store。

### V1 明确不做

- 不承诺全天候后台自动追踪，也不在商店页声称 automatically tracks every drive。
- 不对接网约车、银行或邮箱，不做 1099 申报，不卖审计保险。
- 不做社交、双边市场或通用 AI 聊天。
- 不把车辆保养账本当成 V1 主功能。
- 不暗示 IRS 认证，不承诺能帮用户多退税。
- 不上中国大陆 App Store，不为中国区准备软著、ICP、备案或中文产品页。

## 产品原则

1. 可核对大于全自动：每条记录都能看清起终点、里程和事由，改过的记录要留痕迹。
2. 算对税率：跨越两段税率的年度，按行程日期取对应费率，不用单一数字套一整年。
3. 导出不藏招：付费用户的年度 PDF 与 CSV 必须包含报税常用字段，不要再卖一次导出权。
4. 本地优先：V1 不强制账号。数据默认在设备上，可选 iCloud。
5. 说清楚：商店页、首次引导和导出页脚都要写明，这是账本而不是税务建议。

## 核心流程

```mermaid
flowchart TD
  open([打开 App]) --> start[点开始<br/>使用期间定位]
  start --> drive[行驶中<br/>记录路径点]
  drive --> end[点结束<br/>汇总路径里程]
  end --> purpose[填事由与分类]
  purpose --> edit{需要修改？}
  edit -->|是| adjust[改起终点或切分合并]
  adjust --> save[保存记录]
  edit -->|否| save
  save -.->|税季或报销时| export([导出 PDF / CSV])
```

另一条主路径是手动补记：填日期、起终点、里程、分类和事由后直接保存。若 App 在行程中被杀死，重新打开应恢复未结束行程，并提示用户确认是继续记录还是结束。

## 功能需求

### P0 必做

| 功能 | 要求 | 验收标准 |
| --- | --- | --- |
| 开始/结束行程 | 使用期间定位记路径点，累加实际路径长度，不用起终点直线距替代 | 同一段路多次实测，误差在可解释范围；地图能看起终点与轨迹；定位跳变应被过滤 |
| 手动补记 | 日期、起终点、里程、分类、商务事由、备注 | 无定位时仍能建成一条完整记录；商务类在导出前必填事由 |
| 编辑与切分合并 | 可移动起终点 pin、改里程、将一段拆成多段或合并相邻段 | 混跑时不必删除重录；手改里程会标为已编辑 |
| 分类 | 商务、个人、慈善、医疗 | 列表可按分类筛选；个人行程不计入抵扣汇总 |
| 税率计算 | 按行程日期套用对应区间；2026 年商务为上半年 72.5 美分、下半年 76 美分 | 6 月 30 日与 7 月 1 日的商务行程分别用两档税率；导出中写明区间；税率表可更新 |
| 收据 | 停车费、过路费等可拍照附在行程下 | 照片保存在本地；花费可合计；文案提醒：选用 standard mileage 时，通常不能再把油费重复扣除 |
| 导出 | PDF 与 CSV，含日期、里程、目的地、事由、分类、税率与估算金额 | 付费用户可导出完整自然年；脚注声明供用户与税务专业人士使用，不是税务建议 |
| 多车辆 | 可维护车辆名称并在行程上选车 | 列表和导出能按车过滤 |

### 里程抵扣估算

$$
\text{抵扣估算} = \text{商务里程} \times \text{该日对应的标准里程税率}
$$

跨越半夜或跨越税率变更日的行程，以行程开始日期所属区间为准，并在详情页标注。慈善与医疗类税率须在开发前对照 IRS 官方表补全，本文档不撰写未核实的数字。首页展示当年度商务里程与抵扣估算汇总。

### P1 以后再做

- 可选的后台自动检测行程，且编辑体验必须先于自动检测上线。
- 从远程 JSON 更新税率表。
- 常用目的地与事由套话。
- 设备端识别收据金额，优先用 Vision，不按次走云端大模型。
- 车辆保养附件、Apple Watch 快捷操作、港币等其他单位。
- 是否在美区之外的其他非中国大陆商店上架，视上架后数据再定；中国大陆仍不在范围内。

## 数据模型

| 实体 | 主要字段 | 说明 |
| --- | --- | --- |
| Vehicle | id, name, year, make, model, isDefault | 行程必须归属一辆车 |
| Trip | 起止时间与坐标、地址、路径点、miles、category、purpose、notes、rateApplied、estimatedAmount、source、isEdited | source 为 session 或 manual；手改里程或起终点后 isEdited 为 true |
| RatePeriod | startDate, endDate, category, centsPerMile, source | 内置 2026 年两段商务税率；不可写死为永远 76 美分 |
| Expense | tripId, date, type, amount, photoRef, notes | type 如 parking, toll, other；照片存本地 |
| Settings | defaultVehicleId, unit, icloudEnabled | V1 单位固定为英里 |

日期与汇总按设备本地时区计算。删除行程应可恢复（回收站或撤销），避免误触后无法找回报税记录。

## 计费与权限

| 档位 | 价格 | 权益 |
| --- | ---: | --- |
| 免费 | $0 | 每自然月最多 15 趟；可看列表与近 30 天汇总；不能导出完整年度报表 |
| 月费 | $4.99 / 月 | 无限行程、收据、完整年度 PDF/CSV、恢复购买 |
| 年费 | $39.99 / 年 | 与月费相同；主推荐；含 7 天试用 |
| 终身 | $79.99 一次 | 与年费权益相同，面向讨厌订阅、每年要用一次税表的人 |

- 免费下载，不走周费，不用黑暗模式计费。
- 试用绑定年费。试用期内可用完整导出。
- 付费页博单是可编辑、按日期算对税率、导出不藏、年费 39.99 美元，不是自动追踪。
- 必须提供恢复购买。V1 不强制 Family Sharing。

## 技术方案

| 层次 | 选型 | 备注 |
| --- | --- | --- |
| 客户端 | 原生 SwiftUI + SwiftData，iOS 17+ | 单一工程，优先 iPhone |
| 定位与地图 | Core Location（When In Use）+ MapKit | V1 不申请 Always 权限 |
| 导出 | PDFKit，CSV 本地生成 | 通过系统分享表单送出 |
| 内购 | StoreKit 2，可选 RevenueCat | 月费、年费、终身、试用、恢复购买 |
| 后端 | V1 不需要 | 以后税率表可放静态 JSON；先不上账号体系 |
| 同步 | 可选 iCloud（SwiftData / CloudKit） | 默认关闭，由用户开启 |

上架和 TestFlight 需要付费的 Apple Developer Program（中国大陆个人通过 Apple Developer App 以真实身份注册）。收据识别若做，优先设备端 Vision，不要为了 AI 助手去烧 token。

## 隐私、审核与合规

- 定位仅用于记录行驶里程。Info.plist 说明须写明是 When In Use，不能声称未做到的后台追踪。
- 建议英文权限文案：FairMile uses your location while you record a trip to calculate mileage. Location is not used in the background in this version.
- V1 不把里程、轨迹或收据上传到自有服务器。商店隐私标签与实际收集保持一致。
- 首页、设置与导出页脚必须写：Records are for you and your tax professional. This is not tax advice.
- 不能使用 IRS 标志，不能写 certified 或 guaranteed deduction。
- 收据入口提醒：若选用 IRS standard mileage rate，通常不能再把油费等实际车辆费用重复扣除，以 IRS 规则和会计意见为准。
- 因不上中国大陆商店，V1 不为中国区单独准备隐私政策备案或本地化合规包；美区隐私标签、权限说明和免责声明仍须完整。

## 风险与开放问题

| 风险 | 应对 |
| --- | --- |
| mileage tracker 词非常卷，MileIQ 与 Everlance 品牌强 | 打 IRS mileage log、1099、Schedule C 等更具体词，投入税季内容 |
| 用户付钱常是为了全自动记录，V1 只做开始/结束会偏弱 | 商店页写清；编辑体验先做完，自动检测放到后续可选 |
| 定位权限被拒或审核拒 | V1 只要使用期间权限；说明要写具体，并与实现保持一致 |
| 税率过时或被误读为税务承诺 | 税率可更新；全链路免责；不做认证宣称 |
| 收入季节性强 | 税季前先上架，不为自动追踪打磨到完美再发 |
| 个人开发者卖家名会显示法定姓名 | 这是个人账号的正常结果；商店页把产品能力写清楚，不假装美国公司 |

开放问题：FairMile 这个名字能否用；慈善与医疗类 2026 税率的官方数字；是否已有 Apple Developer Program；终身档是否与年费同步上架。不上中国大陆已确定，不阻止第 1 周先搭模型和行程记录。
